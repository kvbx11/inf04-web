**STOS TECHNOLOGII**

**REACT**
biblioteka JavaScript do tworzenia interfejsu strony/aplikacji, np. przycisków, formularzy, menu czy całych widoków.

**Bootstrap** – gotowy zestaw stylów i komponentów CSS, dzięki któremu można szybko zrobić estetyczną i responsywną stronę.

**Node.js** – środowisko, które pozwala uruchamiać JavaScript poza przeglądarką, np. na serwerze.

**Express** – framework dla Node.js służący do tworzenia serwera i API, np. obsługi adresów /users, /login czy /products.

**MySQL** – system zarządzania bazą danych, w której przechowuje się informacje, np. użytkowników, produkty, zamówienia.
