\*\*GIT - system kontroli wersji\*\*

\*\*NAJWAŻNIEJSZE INFORMACJE\*\*



1\. git init - komenda tworzaca nowe repozytorium

2\. git add \[nazwa pliku / "." dla wszystkich] - dodaje pliki do stage

3\. git commit -m "\[tekst]" - commituje zmiany z stage 

4\. git config \[--local / --global] \[user.name / user.email] – dodanie danych użytkownika do konfiguracji Git. Opcja --local zapisuje je tylko dla bieżącego repozytorium, natomiast --global zapisuje je globalnie dla danego użytkownika, dzięki czemu obowiązują również w innych repozytoriach.

5\. git status - informajca o tym co sie zmienilo i co czeka na stage

6\. git diff - opis co sie zmienilo od ostatniego commita

7\. git branch - lista galezi w repozytorium

8\. git switch \[-c -> utworzenie] \[nazwa galezi] - przeniesienie na inna galaz z ewentualnym jej utworzeniem

9\. git merge \[nazwa\_gałęzi] – połączenie zmian z podanej gałęzi z bieżącą gałęzią.

10\. git remote add origin \["URL do repozytorium GitHub"] - dodanie źródła danych GitHub

11\. git push -u origin \[nazwa galezi] - wyslanie calego brancha na serwer

12\. git pull - pobranie zmian z serwera

13\. git clone \[adres] - sklonowanie calego repozytorium

14\. git branch -M main – zmienia nazwę bieżącej gałęzi na main (-M wymusza zmianę nazwy)

15\. git remote add origin https://github.com/kvbx11/inf04-web.git – dodaje zdalne repozytorium o nazwie origin i przypisuje mu podany adres GitHub.
